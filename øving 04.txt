3. What is the difference between a block cipher and a stream cipher?
    A block cipher breaks the message up into blocks that are transformed in some way block by block, a stream cipher outputs a stream that is XORed 1 bit at a time.

4. What key sizes do you consider “large enough” for symmetric key encryption?

10. What is the F function?
    The F function is one of the steps in teh Lucifer cipher.
    From the book:
        1. Split the 64-bit block into two 32-bit halves, L and R.
        2. Set L to L ⊕ F(R), where F is a substitution–permutation round.
        3. Swap the values of L and R.
        4. Go to step 2 and repeat 15 times.
        5. Merge L and R into the 64-bit output block.

20. What is padding, and why is it necessary?
    A block needs to be a full block of data, so you may need to pad out the block if the message is not long enough.

21. How would you construct symmetric keys? Explain.
    Using the raw input of a password as a key is a bad idea as it would easily be the weakest link (weak to brute force attack). This leaves us with 2 options:
        1. Random number generated from a cryptographically secure random number generator.
        2. Key derived from a password using a Key Derivaton Function. 

22. What is the block size and key size of the DES algorithm?

23. What is CTR and what are the benefits to using CTR?
    CTR = CounTeR mode-of-operations. 
    Since each block is independently calculated and only requires the block, key, and counter, the mode is fast and parallelizable.
    Therefore, you can jump to any block without having to worry about the other blocks (they are not continual for example).
        Useful becuase for example if you drop a packet or have to encrypt a big file, you dont have to restart from teh beginnign if youre interrupted.
    CTR also turns the algorithm into a stream cipher, so you dont need padding.

24. What kind of padding would you use for AES-CTR?
    It doesnt need padding becuase its a stream cipher.

25. CTR is a mode-of-operation for block ciphers. But is AES-CTR a block cipher (explain why/why not).
    AES-CTR is not a block cipher. AES is a block cipher, and CTR is a mode of operation that turns it into a stream cipher.
