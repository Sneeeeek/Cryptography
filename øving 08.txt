6. What does the abbreviation SUCI mean?
    Subscription Concealed Identifier.

7. What is SUPI?
    Subscription Permanent Identifier.
    A unique 15-digit identification number assigned to a mobile subscriber in 5G networks.

8. Why is the “Home Network Identifier” included in the SUCI?
    To let the network who is currently serving you know who to route the concealed identifier to.

9. Why is the “Home Network Public Key ID” included in the SUCI?
    The home network may have multiple keys in use. The key id tell them which key to use for decryption.

10. What is the “Protection Scheme Output” and what does it contain?
    Imagine your real subscriber identity is:
        SUPI = 123456789
    The phone does not send that directly.
    Instead it builds a SUCI like this:
        SUCI = [SUPI type] || [Home Network ID] || [Protection Scheme ID] || [Home Network Public Key ID] || [Protection Scheme Output]
    Example with fake values:
        SUCI = IMSI || xxxxx.home.net || ECIES || 07 || "protected version of 123456789"
    "Im using IMSI + my home is this + Im encrypted with this scheme + I use this key + <the encrypted identity number>"
        Using these, the home network knows what to use and can decrypt the PSO to get my identification number and be quite sure that yep this is snek connecting.

11. What is the SIDF?
    Subscription Identifier De-Concealing Function.
    The function in the home network that takes the SUCI and recovers the hidden SUPI.
    SIDF = deconceal(PSO, key) basically

12. What is GUTI?
    Globally Unique Temporary Identifier.
    A temporary identity the network can assign to a subscriber so the phone does not need to keep sending the permanent identity every time.
    You authenticate with the home network -> The home network confirms you -> Then the serving network assigns you a temporary identity, the GUTI.
    Kinda like a session ID type of deal.

13. The SUCI scheme is not used for most of the accesses. Is that a privacy problem? (explain)
    No. Most of the accesses will be done using GUTI.
